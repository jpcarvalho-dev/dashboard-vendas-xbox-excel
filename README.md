# 📊 Dashboard de Vendas Xbox

Dashboard de vendas do Xbox feito em Excel, para organizar e visualizar dados
de vendas de forma clara. Permite analisar o desempenho das vendas e apoiar a
tomada de decisões. Projeto do Bootcamp Santander - Excel com IA e Claude (DIO).

## Funcionalidades

- Organização dos dados brutos de vendas
- Gráficos e visualizações para análise
- Indicadores de desempenho de vendas

## Como usar

1. Baixe o arquivo da planilha
2. Abra no Excel (2016 ou superior)
3. Consulte o dashboard para visualizar os dados
